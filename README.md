# Ariadne · instaladores

**Android (móvil):** [descargar Ariadne-0.1.1.apk](https://github.com/breixo14/ariadne-releases/releases/download/v0.1.1/Ariadne-0.1.1.apk)
1. Abre el enlace desde el móvil y descarga el APK.
2. Ábrelo. Si lo pide, permite *instalar apps de origen desconocido* para el navegador y vuelve atrás.
3. Pulsa **Instalar**, abre Ariadne y entra con GitHub.
4. Las versiones nuevas te las ofrece la propia app al abrirla.

**Windows (PC):** se instala como app web, no hace falta descargar nada.
1. Abre <https://incandescent-croquembouche-b24d86.netlify.app> en Chrome o Edge y entra con GitHub.
2. Pulsa el icono **Instalar** de la barra de direcciones (o ⋮ → *Enviar, guardar y compartir* → *Instalar Ariadne*).
3. Queda en el menú Inicio con su icono y se actualiza sola.

Para PCs sin Smart App Control también está el instalador [Ariadne-Setup-0.1.1.exe](https://github.com/breixo14/ariadne-releases/releases/download/v0.1.1/Ariadne-Setup-0.1.1.exe) (sin firmar: «Más información → Ejecutar de todas formas»).

Todas las versiones: [Releases](https://github.com/breixo14/ariadne-releases/releases)
